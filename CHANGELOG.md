# История изменений

Здесь перечислены значимые изменения проекта. Структура записей соответствует
формату [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-18

### Добавлено
- Консольная программа последовательно загружает URL 10 раз и выводит среднее
  время запроса, общий объём данных и скорость (Мбит/с и МБ/с).
- Обработка ошибок с остановкой при первом сбое, понятными сообщениями и кодами
  завершения 0, 1, 2 и 130.
- Проверка, что тело ответа не короче объявленного `Content-Length`.
- Параметры `--timeout` и `--version`.
- Модульные тесты и интеграционные тесты с локальным сервером; доступ к интернету
  для их выполнения не нужен.
- CI-процесс для проверки кода, типов и тестов на Python 3.8–3.13 и разных ОС.
- Русская локализация интерфейса и документации.
